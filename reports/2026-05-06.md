## 🔥 DESTAQUES CRÍTICOS

### 1. **OpenAI Agents SDK TypeScript - Sandbox Agents Agora Disponível**

**O que mudou:** OpenAI lançou a versão TypeScript do Agents SDK (6 de maio) com suporte completo para **sandbox agents** e harness open-source integrado.

**Para que serve:** Permite executar agentes em ambientes isolados e controlados com inspeção, customização e controle granular de memória.

**Como aplicar hoje:**
1. Migrar agentes OpenAI para TypeScript SDK
2. Avaliar sandbox agents para workflows que precisam de isolamento
3. Customizar harness open-source conforme necessário
4. Implementar controle de criação e armazenamento de memória

**Impacto:** 🔥 **Alto** (novo primitivo crítico + suporte TypeScript)

---

### 2. **OpenAI chat-latest Snapshot - Modelo Instant em Produção**

**O que mudou:** OpenAI lançou **chat-latest** (5 de maio), snapshot que aponta para o modelo Instant mais recente usado no ChatGPT.

**Para que serve:** Acesso a melhorias mais recentes de chat sem esperar por releases formais. Snapshot é atualizado regularmente.

**Como aplicar hoje:**
1. Testar chat-latest em workflows de chat
2. Avaliar se melhorias justificam migração de GPT-5.5
3. Usar para casos de uso que beneficiam de updates frequentes

**Impacto:** ⚡ **Médio** (novo modelo, mas experimental)

---

### 3. **Anthropic Agents for Financial Services**

**O que mudou:** Anthropic anunciou **Agents for Financial Services** (5 de maio), solução especializada de agentes para setor financeiro.

**Para que serve:** Agentes pré-otimizados para casos de uso financeiros (análise, compliance, operações).

**Como aplicar hoje:** Se a Holdworks tem clientes no setor financeiro, avaliar solução especializada de Anthropic.

**Impacto:** ⚡ **Médio** (novo caso de uso especializado)
