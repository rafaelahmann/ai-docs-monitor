### **OpenAI — Lançamento da Release 2.30.0 do SDK Python**

**O que mudou:** Atualização crítica do SDK (release 2.30.0) com alinhamento de tipos de resposta aos esquemas de itens expandidos e adição do campo `keys` para ações de computador (Click, DoubleClick, Drag, Move, Scroll).

**Para que serve:** Garante que a integração de agentes que usam o Computer Use seja mais precisa, permitindo enviar atalhos de teclado (`keys`) combinados com cliques de mouse, o que simula melhor a interação humana real.

**Como aplicar hoje:** Atualize a biblioteca com `pip install --upgrade openai==2.30.0`. Se você constrói agentes que operam interfaces via Computer Use, comece a usar o parâmetro `keys` para executar atalhos (ex: Shift+Click) diretamente na chamada de ação.

### **Anthropic — Disponibilidade Geral (GA) do Thinking Display Setting**

**O que mudou:** O recurso `thinking-display-setting` saiu de beta e agora está em General Availability (GA) no SDK Python (release 0.85.0+).

**Para que serve:** Permite controlar nativamente como os "pensamentos" (reasoning steps) dos modelos Claude (especialmente Opus e Sonnet 4.6) são exibidos ou omitidos na interface do usuário final, separando o raciocínio da resposta final.

**Como aplicar hoje:** Configure seus agentes na Holdworks para usar este setting, escondendo o bloco de pensamento do usuário final para uma UX mais limpa, mas mantendo o raciocínio nos logs de debug para auditoria.

**Impacto:** ⚡ Médio — Melhora consideravelmente a UX (User Experience) de aplicações baseadas em Claude.

### **OpenAI — GPT-5.4 Mini e Nano em Produção**

**O que mudou:** Confirmação na documentação oficial do lançamento dos modelos `gpt-5.4-mini` e `gpt-5.4-nano` na Responses API. O Mini suporta tool search e computer use, enquanto o Nano é focado apenas em velocidade/custo com suporte a compaction.

**Para que serve:** Estratégia de tiering de modelos. O Nano é para tarefas burras de alto volume (classificação, extração simples). O Mini é o sweet spot para agentes rápidos que precisam usar ferramentas.

**Como aplicar hoje:** Faça um roteamento inteligente na arquitetura da Holdworks. Direcione requests de triagem inicial para o `gpt-5.4-nano` e deixe o `gpt-5.4-mini` para as integrações com ferramentas externas (tool calling).

**Impacto:** 🔥 Alto — Redução drástica de custos operacionais (COGS) mantendo a arquitetura de agentes.
