### **OpenAI — Novos Operadores de Filtro para Comparação**

**O que mudou:** Adicionados operadores `in` e `nin` ao tipo `ComparisonFilter` na API

**Para que serve:** Queries mais eficientes em busca e filtro de dados — não precisa mais fazer múltiplas chamadas para "está em lista"

**Como aplicar hoje:** Se você usa File Search ou Retrieval, comece a usar `{"field": "status", "in": ["active", "pending"]}` em vez de múltiplos filtros

**Impacto:** ⚡ Médio — Melhora performance de queries, especialmente em batch operations

**Como aplicar hoje:** Use em Claude Code ou Agent SDK para criar agentes que aprendem entre sessões. Exemplo: `tools: ["filesystem_memory"]` nas configurações
